## 2. Target experience

### Day-to-day feel
Safe, short, unhurried. Belonging first: "You belong. Grace already found you." Plain words. One clear next step. Identity beats over dumps.

### Target daily rhythm (this persona only)
1. Read — one scripture
2. Listen — optional audio of the short teaching
3. Reflect — keep the existing 2 pathway questions (or fold into the close)
4. End-of-day close (NEW) — short Bible study wrap + exactly 3 gentle questions (see §4)
5. Notes — unchanged

Time budget for the new close: 2–3 minutes. Optional-feeling. Skip allowed. Not graded. Not a full inductive study.

### Sage identity
- Journey UI stays sage.
- Fix global chrome on this path so tab bar active state + primary buttons match sage (not terracotta).
- Optional light identity line in the daily close (e.g. "You are loved. You are new in Christ.") — one line, not a sermon.

## 3. Implementation architecture

### 3.1 Feature flag / persona gate
All new end-of-day behavior only when `persona === 'new_to_faith'` (or equivalent). Other personas keep today's flow unless product later asks otherwise.

```
if (persona === 'new_to_faith') {
  showEndOfDayClose = true
  questionCount = 3
  tone = 'new_believer_formation'
} else {
  showEndOfDayClose = false  // unless separately specified
}
```

### 3.2 End-of-day close module (new)
Suggested component: `EndOfDayClose` (or extend pathway day screen with a final "Close the day" section).

Content shape (fixed for v1):
- Soft re-read prompt: "Notice one line again." (optional tap to highlight / re-read the day's scripture)
- One plain identity line (rotating or static): belonging / grace / new creation — no jargon.
- Exactly 3 questions (see §4). Free-text answers; save to existing notes/reflect store if one exists.
- Optional single next-step chip (not a menu): "One small step of love or obedience."

Do not: add Greek/Hebrew, commentary, leader tools, scoring, streaks pressure, or house ads on this path.

### 3.3 Copy / i18n fixes (same PR or immediate follow-up)
| Issue | Fix |
|---|---|
| "30-Day Faith Pathway" leftovers | Replace with 40-day New & Returning language everywhere this persona can see |
| Day 40 "thirty-day journey" | Change to thirty→forty / "40-day journey" |
| Path sheet vs UI label | Prefer path-sheet: "I'm new to faith, or coming back" or unify both to one string; stop mixing "I'm New to This" / "I'm New" inconsistently |
| "Not sure?" default | "Not sure? Begin Day 1" (or Start Day 1). Reserve Church Member for people who already know Futures |
| Connect Group (first mention) | One-sentence plain explain: "A small group that meets to grow together." |

### 3.4 Soft handoff cards (new, light)
| When | Card |
|---|---|
| After ~Day 14 (and/or Day 40) | "Want a person with you?" → Connect Group / campus / talk to someone at Futures. Same warm tone as Day 1. Explain Connect Group once. |
| After Day 40 | Single clear next step (not a catalog dump). Optional feature of "Who Am I? Found in Christ" labeled in everyday words: "Know who you are to God." |

### 3.5 Mid-path tone pass (content, not only UI)
For days ~15–16, 20, 33 (and any similar): lead with one plain sentence ("This means…") and an optional "come back to this later" so charismatic / warfare language is not a wall for someone who said yes last week. Keep Futures theology; lower the first-timer wall.

### 3.6 Naming clarity (catalog)
Keep New & Returning to Faith (40 days) as the only I'm New path name. Rename or relabel the chapter-only 30-day plan (e.g. "Bible Basics: 30 Days") so it is not confused with the taught 40-day journey. Do not put the 30-day plan in this persona's featured/recommended list.

### 3.7 Chrome / theming
On `new_to_faith`, force sage tokens for: active tab, primary buttons, key CTAs — even if global default is terracotta. Journey cards already sage; chrome must match.

## 4. End-of-day questions (canonical copy)

Use these three every day for this persona (v1). Tone: warm, no wrong answers, no shame.

1. What did you notice about God's heart?
2. Where do you need grace today?
3. One small step of love or obedience — what is it?

Supporting chrome copy (suggested):
- Section title: "Close the day"
- Intro: "Two or three minutes. Skip anything that feels like too much."
- Identity line options: "You belong." / "Grace already found you." / "You are new in Christ."
- Re-read: "Notice one line again."
